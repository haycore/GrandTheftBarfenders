GRAND THEFT BARFENDERS - mod for Barfender
==========================================

Trevor Philips, the arms dealer, stands behind your bar and sells:
  - Halloween pistol (from the shooting gallery), 25 rounds ... 150
  - Bat that looks like the mop .............................. 75
Money comes from the bar's cash. Every pistol hit and every bat hit counts exactly
like a punch with your fist - against customers and other players.
Hitting your own staff with the bat does no damage: it drives them on instead
(20 seconds, +50 % walking speed).

INSTALL
  1. Close Barfender.
  2. Double-click Install.bat.
     - It finds Barfender through Steam (or asks you for the folder).
     - It checks whether MelonLoader is already installed (e.g. by another Barfender
       mod such as "Barfender Staff Roles"). Only if it is missing, MelonLoader 0.7.3 is
       downloaded from GitHub (checksum verified).
     - Other mods stay installed; both mods run together.
  3. Start Barfender. The first start with MelonLoader takes 1-3 minutes.

IN GAME
  Trevor Philips stands behind the bar on his own (the host's game places him).
  E ............ look at Trevor -> shop
  1 ............ draw / holster the pistol
  2 ............ draw / holster the bat
  Left mouse ... shoot / hit
  F6 ........... adjust how the weapons sit in the hand (arrows / Page up/down move,
                 hold Shift to rotate, Backspace resets)
Keys can be changed in UserData\MelonPreferences.cfg, section [GrandTheftBarfenders].

CO-OP
  The host needs the mod (Trevor is a real game character, so guests see him too).
  Guests need the mod to buy and use weapons. Players with the mod see each other's
  weapons (shared through the Steam lobby); players without it don't.

UNINSTALL
  Double-click Uninstall.bat. MelonLoader and the shared fix plugin are only removed
  when no other mod is left.
